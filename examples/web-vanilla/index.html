일반 웹페이지에서 써보기

서버가 세션마다 무작위 배열의 키패드를 만들고, 브라우저는 좌표만 암호화해 보냅니다. 입력창을 누르면 키패드가 열립니다. 데스크톱은 마우스로, 모바일 브라우저는 터치로 사용하세요.

로그인

무슨 일이 일어나나

  1. 브라우저가 임시 X25519 키를 만들고 POST /keypad/session에 보냅니다.
  2. 서버가 이 세션만의 배열을 만들고, 글자 이미지와 키 사각형만 암호화해 내려줍니다. 문자 코드는 없습니다.
  3. 키를 누르면 좌표만 기록됩니다. 로그인 버튼은 좌표 묶음을 암호화한 페이로드를 POST /login으로 보냅니다.
  4. 서버 SDK가 좌표를 글자로 복원하고 세션을 파기합니다. 같은 페이로드를 다시 보내면 410입니다.

배열을 fixed로 바꾸면 키보드는 표준 QWERTY가 되지만 좌표만으로 글자를 알 수 있어 서버가 경고를 남깁니다.
