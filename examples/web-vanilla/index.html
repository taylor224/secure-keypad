실제 서비스에서는 fixed를 쓰지 마세요. 표준 배열이면 좌표만으로 입력값을 알 수 있어 서버가 경고를 남깁니다.

이 화면에서 일어나는 일

  1. 브라우저가 임시 X25519 키를 만들어 POST /keypad/session에 보냅니다.
  2. 서버가 이 세션만의 배열을 만들고 글자 이미지와 키 사각형만 암호화해 내려줍니다. 문자 코드는 없습니다.
  3. 출금 비밀번호와 인증서 비밀번호는 좌표로만 기록됩니다. 화면의 입력창에는 • 만 남습니다.
  4. 이체하기를 누르면 좌표 묶음이 암호화되어 POST /login으로 가고, 서버 SDK가 값을 복원한 뒤 세션을 파기합니다.

QWERTY 키패드는 지구본 키로 한국어(두벌식) ↔ 영어를 바꿉니다. 한글 자모는 서버에서 음절로 조합됩니다.

아래 결과 카드는 데모라서 서버가 복원한 값을 그대로 보여줍니다. 실제 은행이라면 값은 서버 밖으로 나가지 않습니다.
