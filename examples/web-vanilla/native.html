secure-keypad 데모 — 차돌이뱅크는 실제 은행이 아닙니다. 프로젝트 저장소

iOS · Android 네이티브 SDK 예제

브라우저 시뮬레이션은 캔버스로 그린 모사입니다. 실제 앱에서는 아래 SDK가 시스템 키보드 자리에 네이티브 키패드를 띄우고, 서버 SDK가 좌표를 글자로 복원합니다. 두 SDK 모두 한국어(두벌식) + 영어 키패드와 지구본 키를 지원하며, 한글 조합은 서버에서 일어납니다.

iOS — Swift Package clients/ios

요구 사항iOS 14+, CryptoKit · UIKit만 사용 (외부 의존성 없음)
설치Xcode → File → Add Package Dependencies → 저장소 URL, 경로 clients/ios, 제품 SecureKeypad
데모 실행clients/ios/Examples/DemoViewController.swift를 새 iOS 앱 타깃에 넣고 sessionURL을 예제 서버로 바꿉니다 (시뮬레이터: http://localhost:3789, cd examples/server-node && npm run demo).
테스트cd clients/ios && swift test — 벡터 재생, 시뮬레이터에서는 xcodebuild test로 키패드 뷰 테스트까지
import SecureKeypad

var config = SecureKeypad.Config(
    sessionURL: URL(string: "https://api.example.com/keypad/session")!,
    type: .qwerty,
    serverPublicKey: "BASE64_ED25519_FROM_skp-keygen")
config.relayoutURL = URL(string: "https://api.example.com/keypad/relayout")
config.maxLen = 32
config.languages = ["ko", "en"]          // 한국어 먼저, 지구본 키로 영어 전환 (생략하면 서버 기본값 en, ko)

let keypad = SecureKeypad(config: config)
keypad.attach(to: passwordField)          // inputView 교체, 필드에는 • 만 표시
keypad.onLanguageChange = { code in print("keyboard:", code) }
keypad.onDone = { [weak self] in self?.login() }

func login() {
    let payload = try keypad.submit()    // {"v":1,"sid":"…","ct":"…"} → 서버 SDK decrypt()
    api.login(userId: idField.text ?? "", passwordEnc: payload)
}

키패드는 UIInputView라 시스템 키보드처럼 올라오고, 화면 녹화·스크린샷 중에는 가려집니다. 글자는 서버가 그린 스프라이트를 붙여 그리므로 앱은 어떤 글자가 눌렸는지 모릅니다.

Android — AAR 모듈 clients/android/secure-keypad

요구 사항minSdk 24, Kotlin, BouncyCastle (X25519 · Ed25519 · ChaCha20-Poly1305). AndroidX 의존성 없음
설치settings.gradle.kts에 include(":secure-keypad") + project(":secure-keypad").projectDir = file("…/clients/android/secure-keypad"), 앱에서 implementation(project(":secure-keypad"))
데모 실행Android Studio로 clients/android를 열고 demo 모듈 실행. 에뮬레이터에서는 DemoActivity.SERVER = "http://10.0.2.2:3789"가 호스트의 예제 서버를 가리킵니다.
테스트cd clients/android && ./gradlew :secure-keypad:testDebugUnitTest — 벡터 재생 (JVM)
val keypad = SecureKeypad(this, SecureKeypad.Config(
    sessionUrl = "https://api.example.com/keypad/session",
    relayoutUrl = "https://api.example.com/keypad/relayout",
    serverPublicKey = "BASE64_ED25519_FROM_skp-keygen",
    type = KeypadType.QWERTY, maxLen = 32,
    languages = listOf("ko", "en"),     // 한국어 먼저; 생략하면 서버 기본값 (en, ko)
))
keypad.attach(passwordEditText)          // 시스템 키보드 차단, 필드에는 • 만 표시, FLAG_SECURE
keypad.onLanguageChange = { code -> Log.d("keypad", code) }

lifecycleScope.launch {
    val payload = keypad.submit()        // '{"v":1,"sid":"…","ct":"…"}' → 서버 SDK decrypt()
    api.login(userId, passwordEnc = payload)
}

키패드가 보이는 동안 FLAG_SECURE가 걸려 스크린샷과 화면 녹화가 막힙니다. 스페이스바에 현재 언어가 표시되고 지구본 키가 언어를 순환합니다.

서버 쪽 — 언어 정하기

서버 SDK의 languages 옵션이 최우선입니다. 지정하지 않으면 클라이언트가 요청한 opts.langs를 따르고, 둘 다 없으면 영어 + 한국어입니다. 숫자 키패드에는 적용되지 않습니다.

// Node
await skp.createSession(req.body, { ctx, languages: ["ko", "en"] });
# Python
skp.create_session(body, ctx=ctx, languages=["ko", "en"])
// Java
skp.createSession(body, SessionOptions.builder().ctx(ctx).languages("ko", "en").build());

복호화 결과에서 한글 자모는 두벌식 규칙으로 음절로 조합됩니다 (spec/HANGUL.md). 예: ㅎ ㅏ ㄴ ㄱ ㅡ ㄹ → 한글, ㄷ ㅏ ㄹ ㄱ ㅏ → 달가.
